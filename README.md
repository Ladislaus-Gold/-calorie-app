# Калории

Личный дневник питания: вход через Google, продукты с КБЖУ на 100 г, расчёт по граммам,
сканер штрих-кодов, поиск в Open Food Facts, отчёты.
Хранение: Firebase (Authentication + Firestore). Хостинг: GitHub Pages.

## Файлы
- `index.html`, `style.css`, `app.js`, `starter.js` — само приложение (starter.js — набор базовых продуктов)
- `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — установка на экран телефона
- `firestore.rules` — правила доступа: каждый видит только свои данные

## Как обновить версию на GitHub
Репозиторий → Add file → Upload files → перетащить `index.html`, `app.js`, `style.css`, `starter.js`
(одноимённые файлы заменятся, `starter.js` добавится) → Commit changes. Через 1–2 минуты сайт обновится.
Если на телефоне виден старый вид: закрыть приложение полностью и открыть снова,
а при необходимости удалить значок с экрана «Домой» и добавить заново.

## Что нового в версии 7
- Новая иконка приложения (сердце с пульсом, вода, яблоко, пламя): `icon-192.png`, `icon-512.png`,
  `apple-touch-icon.png` и версия с полями для Android `icon-maskable-512.png`.
  Чтобы иконка обновилась на телефоне, удалите значок с экрана «Домой» и добавьте заново.

## Что нового в версии 6
- Зелёное оформление, полные названия БЖУ, меньший шрифт в диаграмме.
- Вкладка «Здоровье»: вода, нагрузки, недельный прогресс; профиль и расчёт плана (калории, БЖУ, вода, нагрузка).

## Что нового в версии 5
- Общая база продуктов: продукты видят и добавляют все пользователи, у каждого продукта указан автор.
  Править и удалять продукт может только автор. Дневник и цель по калориям остаются личными.
- Прежние личные продукты переносятся в общую базу автоматически при первом входе.
- Базовый набор добавляется в общую базу один раз для всех (повторов нет).
- Оформление в стиле проекта Accounting: системный шрифт iPhone, палитра, скругления, карточки, нижнее меню, размеры текста.
- Иконка стала синей, как в Accounting.

## Что было в версии 4
- Новый распознаватель штрих-кодов (ZXing-C++ на WebAssembly): лучше читает мятые, наклонные и слегка размытые коды.
  При первом сканировании скачивается около 1 МБ, нужен интернет.
- Кнопка «Сфотографировать код»: обычная камера телефона с автофокусом, затем код читается с фото.
- Запрет масштабирования щипком и двойным касанием.
- Если распознаватель не загрузился, включается запасной (ZXing для JavaScript).

## Что было в версии 3
- Сканер штрих-кодов камерой (кнопка в «Добавить еду», в «Продукты» и в карточке продукта) и ручной ввод кода.
- Поиск продукта по коду: сначала в вашем списке, потом в Open Food Facts; если нигде нет, данные вводятся один раз.
- Поиск по названию в Open Food Facts (по кнопке, у сервиса лимит 10 запросов в минуту).
- Базовый набор из 114 продуктов, у многих есть варианты: сырой, варёный, запечённый, жареный.
- Поиск не различает «е» и «ё» и понимает несколько слов («куриная жарен»).
- Защита от дубликатов штрих-кода.

## Где что лежит в базе
- `products` — общая база продуктов (значения на 100 г, автор, штрих-код)
- `users/{uid}/entries` — записи дневника (дата, приём пищи, граммы, посчитанные КБЖУ)
- `users/{uid}/settings/profile` — дневная цель по калориям

## Источники данных
Open Food Facts (лицензия ODbL), справочные таблицы состава продуктов.
